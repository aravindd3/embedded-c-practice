# Embedded C Practice

A structured collection of C programming drills focused on core embedded systems and firmware development concepts.

## Scope
This repository contains daily exercises targeting the hardware-software boundary, specifically focusing on:
* **Bit Manipulation:** Masking, setting, clearing, and toggling simulated hardware registers.
* **Memory Management:** Pointer arithmetic, volatile casting, and buffer manipulation.
* **Architecture:** Struct packing, bit fields, and function pointers for state machines.

## Environment
* **Language:** C (C99/C11 standards)
* **Compiler:** GCC
